# Weather-Aware Truck Routing

Helps a truck driver pick the safest route between two places, based on the weather along the way, the load weight and the travel time.

Work in progress.

## Stack

- Backend: Python, Django, Django REST Framework
- Frontend: React, TypeScript, Material UI, MapLibre
- Routing and geocoding: HERE (truck mode)
- Weather: Open-Meteo
- Hosting: Google Cloud Run
